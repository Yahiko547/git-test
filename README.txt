FORGE Workout Tracker — PWA

Что внутри:
- index.html — приложение
- manifest.webmanifest — данные для установки на домашний экран
- sw.js — офлайн-кэш
- icons/ — иконки приложения

Важно:
1. Приложение не использует внешние CDN, Google Fonts или API. После первой загрузки через HTTPS оно может работать офлайн.
2. Для полноценной установки на iPhone как отдельной иконки откройте приложение в Safari по HTTPS, затем:
   Поделиться → На экран «Домой» → Добавить.
3. Service Worker не работает через обычный file://. Для теста на компьютере можно открыть index.html напрямую, но режим PWA/offline-install требует HTTPS или localhost.
4. Для размещения подходит любой обычный статический HTTPS-хостинг. Достаточно загрузить содержимое этой папки без изменений.
5. Доступность конкретного зарубежного хостинга в России может меняться. Само приложение не требует VPN и не обращается к внешним сервисам; после установки/кэширования оно работает локально.
